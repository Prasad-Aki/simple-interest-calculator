# simple-interest-calculator

Description

This project calculates simple interest based on the principal amount, annual interest rate, and time period.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Inputs

Principal: The initial amount of money.

Rate: The annual interest rate in percentage.

Time: The duration in years.

Example

Principal: 1000

Rate: 5%

Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Result: Simple Interest = 100

Purpose

This project demonstrates the basic calculation of simple interest using a straightforward mathematical formula.
